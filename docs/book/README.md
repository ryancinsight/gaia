# Gaia Mesh Book

Gaia is the Atlas stack's mesh-generation source of truth. This book records
the public mesh-building contract, the provider boundaries used by Gaia, and
the generated figures that are reviewed from real `IndexedMesh` values.

The gallery is generated by the repository binary
`book_mesh_gallery`. It is not a collection of hand-drawn illustrations or
placeholder geometry. Re-run the generator after a mesh-builder contract
change, review the resulting sheets, and build this book before delivery.
